# JobApplicationTracker
A full-stack web application designed to help job seekers efficiently track, manage, and optimize their job applications in one place. 

This tool allows users to organize applications accross multiple companies, monitor progress through different stages (applied, interview, offer, rejected), and maintain a structured job search workflow.

**Features**
- Track job applications with company name, role, location, and status
- Update application stages (Applied -> Interview -> Offer -> Rejeected/Accepted)
- Add notes, contacts, and follow-up reminders
- Timeline view of job search progress
- Search and filter applications easily
- Dashboard insights for better tracking and decision-making

**Tech Stack**
- Frontend: React.js
- Backend: Node.js/ Express
- Database: MongoDB/ SQL (customizable)
- Other: REST APIs, Github for version control

**Purpose**

Built to simplify the job hunting process by providing clarity, organisation, and better follow up, especially useful for candidates applying to multiple roles simultaneously.

**Future Enhancements**
- Resume and cover letter version tracking
- Email integration for automatic updates
- Analytics (response rate, interview success rate)
- ATS scoring insights
